# Images Folder

Add all your website images here. The website is ready to display them immediately!

## Quick Start

1. Add your JPG/PNG images to this folder
2. Match the filenames to those in `PUBLIC_IMAGES_NEEDED.md`
3. Run `npm run dev` to see them live

## Image List

See `PUBLIC_IMAGES_NEEDED.md` in the project root for:
- Complete list of all 23 images needed
- Recommended dimensions for each
- Where each image appears on the site
