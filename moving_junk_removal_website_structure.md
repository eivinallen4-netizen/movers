# Moving & Junk Removal Website Structure

## 1. Header / Navigation

### Layout
- White or very light background.
- Logo on the left.
- Navigation: `Moving` / `Junk Removal` / `Services` / `Reviews` / `FAQ`
- Primary CTA on the right: **Get a Free Quote**
- Mobile: logo + hamburger + persistent quote button.

### Non-Text Elements
- Small animated moving-truck or box icon next to the CTA.
- Header becomes slightly smaller on scroll and gains a subtle shadow.
- CTA button includes a small arrow that moves on hover.

---

## 2. Hero — “Make the Move. Lose the Junk.”

The hero should be the biggest visual statement on the website.

### Layout

**Left**
- Large headline
- Short supporting copy
- Two CTAs:
  - **Get a Free Quote**
  - **See Our Services**

**Right**
- Large photographic composition showing:
  - Moving truck
  - Two movers carrying a couch
  - Boxes
  - A small amount of junk being loaded

Instead of one generic stock photo, make it feel like an editorial collage.

### Non-Text Elements

Use objects that partially break outside their image containers:

```text
             ┌──────────────────────┐
             │                      │
             │    MOVING TRUCK      │
             │                      │
             └───────────┬──────────┘
                         │
       ┌──────────────┐  │
       │  MOVER +     │  │
       │   COUCH      │  │
       └──────────────┘  │
              📦     📦
```

Add:
- Floating box
- Furniture silhouette
- Tape graphic
- Small route line
- Location pin
- “Moving → Done” visual progression

The visual should communicate **action**, not simply show a truck.

---

## 3. Trust Bar

Immediately underneath the hero.

Instead of another paragraph, create a horizontal strip containing visual proof.

### Elements

- **★★★★★** — Customer rating
- **✓** — Careful handling
- **✓** — Upfront pricing
- **✓** — Residential + Commercial
- **✓** — Moving + Junk Removal

Each item gets:
- Icon
- Short label
- Small divider

### Mobile
Turn the trust bar into a horizontally scrollable strip.

#### Appliance Removal

#### Garage Cleanout

- Image zooms slightly.
- Arrow slides right.

# Overall Visual Direction

Do **not** make this look like a typical moving company website.

### Avoid
- Stock photo of a smiling guy holding a cardboard box
- Endless blue sections
- Generic house icons
- 20 paragraphs of copy
- Huge “WELCOME TO OUR COMPANY” headline
- Every service being a basic rectangle
- Generic WordPress-style testimonial blocks

### Instead

Make it feel like:

**Modern service brand + logistics company + premium local business.**

Use:
- Large photography
- Oversized typography
- Strong brand color
- High-contrast sections
- Custom illustrations
- Before/after sliders
- Interactive service cards
- Animated truck
- Moving arrows
- Route lines
- Location pins
- Custom icons
- Real job photography
- Review cards
- Multi-step quote form
- Sticky mobile CTA

---

# Core Visual Idea

The entire website should communicate:

## PROBLEM → ACTION → RESULT

### Junk Removal

**Problem:**  
“I have 2,000 lbs of junk in my garage.”

**Action:**  
Truck arrives → Crew loads it → Space gets cleared.

**Result:**  
Clean, usable garage.

### Moving

**Problem:**  
“I need to move this couch.”

**Action:**  
Crew arrives → Wraps it → Carries it → Loads it.

**Result:**  
Furniture moved safely.

The website should **show this transformation visually**, rather than simply telling visitors:

> “We’re reliable, affordable, and efficient.”
