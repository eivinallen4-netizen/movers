## Tips for Best Results

1. **Consistency**: Use a consistent style and color grading across all images
2. **Real Photos**: Use actual work photos rather than generic stock photos when possible
3. **Portrait/Landscape**: Make sure images match their container aspect ratios
4. **Quality**: Use high-quality, well-lit images (minimum 1200px wide for hero)
5. **File Format**: JPG works best for photos. Optimize for web (compress if needed)

## How to Add Images

1. Create folder: `public/images/`
2. Place all image files in that folder
3. Images will automatically be served and used by the website
4. The website is already configured to display them!

## Testing

Once you've added images to `public/images/`, run:
```bash
npm run dev
```

Then visit http://localhost:3000 to see your website with all images live!
